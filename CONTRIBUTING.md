# Contributing

Thanks for helping improve the AI Use Case Registry.

1. **Open an issue first.** Use the **Bug report** or **Feature request** form. That way we can agree on the change before you work on it, and your pull request can reference the issue.
2. **Then open a pull request** that links the issue (for example "Closes #12"). Run the tests with `node --test` before you do.

Have a question, an idea that isn't a bug or a feature, or not sure where something fits? Start a thread in [Discussions](../../discussions).

Please report security problems privately, through **Security → Report a vulnerability**, not in an issue or discussion.
